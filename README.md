# American Rescreening — Website Mockup

Static mockup of the new american-rescreening.com, built ahead of the Webflow rebuild.

- `build.mjs` — zero-dependency static site generator (`node build.mjs` → `dist/`)
- `src/` — layout, stylesheet, and page content
- `content/posts.json` — all 33 blog posts migrated from the old WordPress site
- `assets/images/` — images pulled from the old site

Deployed on Vercel. Forms are non-functional placeholders — the production site will use native Webflow forms.
